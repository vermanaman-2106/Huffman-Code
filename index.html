8. Algorithm and Time Complexity

Huffman Coding repeatedly combines the two nodes with the smallest frequencies to construct an optimal prefix code. This is a greedy strategy: at each step the two currently cheapest nodes are merged, and the resulting prefix codes are optimal for the given frequencies.

  • Frequency counting: O(n)
  • Huffman tree construction using a min-heap: O(k log k)
  • Encoding: O(n), excluding output-size costs
  • Decoding: O(encoded bit length)

Here, n is the length of the input text (number of characters) and k is the number of distinct characters in that text. Building the tree does O(k) heap insertions of leaves, then O(k) merge steps. Each heap operation costs O(log k), so tree construction is O(k log k).
